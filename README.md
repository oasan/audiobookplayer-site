# Сайт приложения «Аудиокниги»

Публичная страница приложения и его политика конфиденциальности.
Публикуется через GitHub Pages из ветки `main`, папка `/ (root)`.

- `index.html` — страница приложения.
- `privacy.html` — политика конфиденциальности, ссылка на неё указывается
  в Play Console.
- `assets/style.css` — общие стили; палитра повторяет роли из приложения
  (`ui/theme/Color.kt`), светлая и тёмная темы.
- `assets/golos-text.ttf` — вариативный Golos Text, тот же шрифт, что
  в приложении. Лицензия OFL — `assets/golos-text-OFL.txt`.
- `.nojekyll` — отключает обработку Jekyll: страницы отдаются как есть.

Тексты взяты из `deploy/описание.md` и `deploy/политика-конфиденциальности.md`
основного репозитория. При изменении политики в приложении менять оба файла.

Локальный просмотр: `python3 -m http.server 8000` из этой папки.
