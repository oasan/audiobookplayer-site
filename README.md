# Сайт приложения «Аудиокниги»

Публичная страница приложения и его политика конфиденциальности.
Публикуется через GitHub Pages из ветки `main`, папка `/ (root)`:
https://oasan.github.io/audiobookplayer-site/

- `index.html` — лендинг. Стили, палитры всех тем (роли из `Color.kt`
  приложения) и скрипт — внутри файла.
- `img/<тема>/*.webp` — снимки экранов, шесть тем. Исходные PNG —
  в репозитории assets (`screens/`), сюда кладутся только сжатые копии.
- `fonts/` — Golos Text и JetBrains Mono, вариативные, OFL.
- `privacy.html` — политика конфиденциальности. Её адрес указан
  в Play Console — **не переименовывать и не переносить**. Единственный
  источник текста политики — этот файл.
- `assets/style.css`, `assets/icon.webp` — стили и значок страницы политики.
- `.nojekyll` — отключает обработку Jekyll: страницы отдаются как есть.

Кнопки «Скачать APK» в `index.html` ведут на последнюю сборку в GitHub Releases:
https://github.com/oasan/audiobookplayer-site/releases/latest/download/audiobookplayer.apk

## Публикация новой сборки

1. Проверить версию и подпись релизного APK.
2. В этом репозитории создать релиз с тегом `v<versionName>-<versionCode>`
   (например, `v1.0-9`) и описанием изменений.
3. Прикрепить APK с постоянным именем **`audiobookplayer.apk`**.
4. Опубликовать релиз и отметить его как **Latest**. Предварительные релизы
   не использовать для кнопок сайта.
5. Проверить скачивание по ссылке выше. Менять сайт для каждой версии не нужно.

APK прикрепляется к релизу, в Git его не добавлять. AAB предназначен для
Google Play, `mapping.txt` хранится локально вместе со сборкой.
Тег в этом репозитории отмечает состояние сайта; исходники приложения
хранятся отдельно. После публикации в Google Play можно добавить рядом
отдельную кнопку магазина.

Репозиторий публичный: ничего закрытого сюда не класть.

Локальный просмотр: `python3 -m http.server 8000` из этой папки.
